# EMAÚS

Aplicación católica de acompañamiento del duelo para Android y iPhone.

## Ruta maestra

La arquitectura y las decisiones vigentes están en `docs/ARQUITECTURA_TECNICA_V1.md`.

## Estructura actual

- `apps/mobile`: aplicación Expo / React Native.
- `docs`: especificaciones y arquitectura.
- `identidad visual`: activos visuales de referencia.

## Principio central

EMAÚS acompaña, orienta y sostiene. No diagnostica, no sustituye ayuda profesional y mantiene la esperanza cristiana en el centro.
